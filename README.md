# Oasis Infobyte Internship Projects

This repository contains my Data Science projects completed during the Oasis Infobyte Internship Program.

## Completed Tasks

### Task 1: Iris Flower Classification
- Classified Iris flower species using Machine Learning.
- Implemented Logistic Regression and KNN.

### Task 2: Unemployment Analysis in India
- Analyzed unemployment trends in India.
- Explored regional and rural-urban unemployment patterns.

### Task 3: Car Price Prediction
- Predicted car prices using Machine Learning.
- Implemented Linear Regression and Random Forest.
- Achieved an R² score of 0.9566 using Random Forest.
