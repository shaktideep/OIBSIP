# Iris Flower Classification

## Project Overview
A Machine Learning project that classifies Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Dataset
- Dataset: Scikit-learn Iris Dataset
- Total Records: 150
- Features: 4
- Classes: 3

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-Score

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis
3. Data Visualization
4. Feature Selection
5. Train-Test Split
6. Feature Scaling
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Prediction

## Conclusion
This project demonstrates Iris flower classification using two Machine Learning algorithms.
