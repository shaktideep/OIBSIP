# Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends across different regions of India using Python and data visualization techniques.

## Dataset
- Dataset: Unemployment in India
- Source: Kaggle
- Original Records: 768
- Columns: 7

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. State-wise Unemployment Analysis
5. Rural vs Urban Comparison
6. Monthly Unemployment Trend
7. Labour Participation Rate Analysis
8. Correlation Heatmap
9. Unemployment Rate Distribution
10. Key Findings

## Visualizations
- Bar Chart
- Line Chart
- Histogram
- Boxplot
- Correlation Heatmap

## How to Run
1. Install the required libraries.
2. Keep the CSV dataset in the project folder.
3. Open `Unemployment_Analysis.ipynb`.
4. Run all notebook cells.

## Installation

```bash
pip install -r requirements.txt
```

## Project Files
- `Unemployment_Analysis.ipynb` – Analysis and visualizations.
- `Unemployment in India.csv` – Dataset.
- `README.md` – Project documentation.
- `requirements.txt` – Required Python libraries.

## Conclusion
This project explores unemployment patterns across Indian regions, compares rural and urban unemployment, and examines trends using statistical analysis and visualizations.
